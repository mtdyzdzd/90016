# Sprint 2 Evidence Folder

This folder is kept as a public-facing evidence set for Sprint 2. It contains:

- accepted Sprint 2 chart output,
- live-site verification notes,
- reduced school-location CSV evidence,
- nearest-six secondary-school evidence,
- WP Go Maps import/filter CSV evidence,
- one CSV-generation helper script used to reproduce and verify the dataset reduction.

Temporary page backups, local browser previews, page-generation scripts, and raw WP backup JSON files are intentionally excluded from the formal evidence set. Those files were useful during local restoration and checking, but they are not needed for a reviewer-facing repository.
